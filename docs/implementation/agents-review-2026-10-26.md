# Проверка AGENTS.md по официальной документации OpenAI

26 октября 2026 года. Поручение: оценить и улучшить инструкцию для работы с Matigr из других чатов. Исходный HEAD — `3c9831a`; ветка `codex/implementation-v0`, рабочее дерево до правки чистое.

## Оценка

Прежний файл содержал правильные договорённости: завершённый MVP, владение сервисами, ограничения бизнес-процессов, проверки и сохранение данных. Недостатки — повторение истории/статусов, обязательное чтение большого набора документов для любой задачи и отсутствие компактной карты кода и команд по типам изменений.

## Источники и принятые изменения

- [Официальное руководство AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md): инструкции обнаруживаются по каталогам; более близкие к рабочему каталогу уточняют общие, override имеет приоритет в своём каталоге. Общий размер по умолчанию ограничен 32 КиБ. В корне оставлена общая инструкция; искусственные вложенные инструкции и изменение глобальной конфигурации не понадобились.
- [Рекомендации OpenAI по инструкциям и контексту](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra): держать инструкции актуальными, направлять чтение по задаче, избегать чрезмерных предписаний и повторных проверок без причины. Вместо чтения всей архитектуры перед любой правкой добавлена таблица источников по теме.

Добавлены назначение приложения, карта кода, точные команды из существующих scripts/package.json, порядок входа и передачи результата. Сохраняются бизнес-инварианты, неизвестные вопросы, порядок новых функций и границы полномочий. Подробная история остаётся в существующих документах, важные решения следующей задачи должны попадать в отслеживаемые файлы.

Инструкция помогает восстановить контекст из репозитория, но не переносит переписку, незакоммиченные файлы или новые коммиты в другую копию. Для другого чата нужен актуальный checkout. Автоматическая загрузка всех вложенных инструкций при работе из корня не обещается.
