# V1 — первичная проверка и публикация

Владелец базового сценария — CHK-E2E-01; расширение второго посетителя/личного экрана — RES-E2E-01. Использовать отдельный Compose-проект и неизменные fixtures. Не сбрасывать рабочие volumes. HTTP/broker/SQL fault gates выполняются до браузерного сценария.

## Браузерный сценарий

1. Открыть `/checking`, выбрать «Жюри 1». В отдельной вкладке гостя открыть `/results?tournamentId=0344e06b-4ea1-582e-bd91-e832719773f2`.
2. Остановить только Results API тестового проекта. Через «Взять следующую» получить подготовленную проверку; открыть материал и сверить команду/задачу. Отметить «Правильно».
3. До запуска Results взять следующую проверку тем же жюри. Новый материал/задача подтверждают освобождение после commit Checking, без ожидания обработки Results. Отметить «Неправильно», не вводя комментарий.
4. Запустить Results. Дождаться ожидаемых ячеек анонимной таблицы; ждать наблюдаемого состояния/версии, не фиксированную задержку. Положительный исход даёт фиксированные баллы задачи, отрицательный — Published 0, остальные ячейки остаются Pending.
5. Сверить по ID результаты/версию снимка через публичный GET и durable receipt. Гость не получает материал/назначение/авторство. Ни UI, ни Checking не вычисляют сумму/места Results.

## Исполнение 24 октября 2026

На `matigr-remaining-faults` выполнен браузерный сценарий через реальный Vite/Checking/PostgreSQL/RabbitMQ/Results. Проверены Бета/задача 1 (Correct, 10), затем Бета/задача 2 (Incorrect, 0). Между двумя проверками Results API был остановлен. UI показал освобождение и новое назначение до восстановления Results. После старта Results анонимная вкладка сама обновилась: Альфа 30/место 1, Бета 10/место 2, Гамма Pending/0/место 3. Материал Беты прочитан только текущим жюри. Скриншот исполнения хранится локально вне Git: `.local/e2e/v1-standings.png`.

Сценарий выполняется браузером; `check-live-results.mjs`, `check-checking-faults.mjs`, `check-results-faults.mjs` и persistence tests дополняют его автоматическими проверками wire/версий/сбоев. Они не подменяют прохождение UI. Эта запись не объявляет завершёнными будущие V3–V6.
